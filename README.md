# Diario dell'Uncinetto

App per il telefono per seguire i progetti all'uncinetto: contagiri per ogni parte del capo, promemoria per giro, timer, maglie, filati e conversione cm ↔ giri dal campione.

**Apri l'app:** https://mircosacc8.github.io/diario-uncinetto/

Su iPhone: apri il link in Safari → Condividi → **Aggiungi alla schermata Home**.
